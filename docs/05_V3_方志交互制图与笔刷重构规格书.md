## 第 0 章 V2.0 病根复盘与 V3.0 核心转向（为什么必须这样改）

V2.0 虽然实现了 TS 静态安全与零穿模计数，但存在五项致命短板导致无法实际使用：
1. **交互工具平铺且缺选项栏**：左侧 12 按钮一字排开，切子模式必须去右侧来回切 Tab；
2. **笔刷手感与性能双崩**：悬停时不触发重绘导致笔刷圈僵死、拖快断珠/拖慢叠爆、无硬度平顶核、无斜坡/阶地/擦除/林木笔刷，且每像素 `pointermove` 都全图跑等高线 + Base64 编码 + 无离屏缓存全城重绘；
3. **缺少方志级水工与核心建筑群实体**：只能贴 15px 圆点地标，无法表达分水堰、滑道码头、水力工坊、双桥头堡、城中套城大院及 `L/U/圆坛/公仓` 精准单体；
4. **选区生成与渲染质量失真**：全图 30 个选区全是 4 顶点矩形、城坊无视路网糊成棕白碎渣、农田描粗黑框变龟裂地砖、`market` 步距多乘 `0.5` 挤成中心黑团、`lanes` 和 `exclusionPolys` 漏绘、地形缺高程淡彩与顺坡晕滃、图饰按视口而非图框 `frame` 定位导致穿框；
5. **三套预设工程违背方志设定**：官坛放错岸、堡寨挪出城、水渠乱断头、桥梁错位。

V3.0 以**三阶段**彻底根治以上全部问题，并引入**几何与视觉反丑陋自动化门禁**（不仅验“零穿模”，更验“像真地图”）。

> **关于 V2.0 旧约束的显式修订**：
> - **修订 `NG-01`**：普通居民区（`walled_city / town_blocks / village` 数千栋程序化民居）依然保持选区抽卡、不逐栋手摆；**但明确开放“核心建筑群/礼制单体（`structures`）”与“水工结构件（`weirs / docks / watermills / bridgeOverrides`）”的一级新建、点选、拖拽、旋转、缩放与精确数值编辑**。
> - **修订 V2 僵化测试断言**：更新 `tests/renderer-and-ui-parity.test.ts` 中写死的 `TOOL_IDS.length === 12`、`files.length === 56`、`layerIds.length === 14` 与旧视口坐标 `rect.x === 16` 断言，升级为 V3 新契约（但**保留** `src/` 下所有 `.ts/.tsx` 单文件 `<= 320` 行、零 `any`/`TODO`/`Math.random`、Canvas/SVG 同源一致性与零穿模铁律）。

### 2.3 笔刷引擎全面重做（`src/core/terrain/terrainSculpt.ts` + `src/ui/canvasStageInput.ts`）
1. **彻底修复悬停光标僵死**：`move` 处理器在 `!drag` 且 `activeTool` 为 `sculpt_brush | contour_drag | tree_brush` 时必须置 `refs.dirty.current = true`，确保光标丝滑跟随。
2. **双圈光标 + 随手读数芯片**：在 `paintScene` 的 `ui-overlay` 层为 `sculpt_brush / contour_drag / tree_brush` 绘制：
   - 外虚线圈：总影响半径 `R`；
   - 内实线圈：平顶核心半径 `R * hardness`（仅地形笔刷）；
   - 右下悬浮微型芯片：实时显示光标海拔 `484.2 m`（推平显示 `→ 484 m`；斜坡拉道拖拽中显示起止虚线 + `起点 Z → 终点 Z (坡度°)`；按住 `Alt` / `Shift` 时显示临时模式徽标如 `下压` / `平滑` / `擦除`）。
3. **等距弧长插值与硬度核（消除断珠与火山锥）**：
   - 新增 `applySculptStrokeSegment(field, terrainConfig, from, to, brushCtx, options)`：沿 `from -> to` 以 `spacing = Math.max(3.0, radiusM * 0.22)` 等距步进插值落笔，并将单步增量按步长比例归一化；
   - **硬度衰减核（Hardness / Plateau Kernel）**：设 `u = r / radiusM`，`h = clamp(hardness, 0, 0.95)`：当 `u <= h` 时权重 `w = 1.0`；当 `h < u < 1` 时令 `t = (u - h) / (1 - h)`，`w = (1 - t²)²`（或余弦平滑 `0.5*(1+cos(πt))`）。由此 `h = 0` 为柔和缓丘，`h = 0.75` 可一笔刷出平顶陡边河阶台地！
   - **7 种地形笔刷模式**：
     - `raise` / `lower`：按住 `Alt` 临时反向；按住 `Shift` 临时切 `smooth`；
     - `flatten`：支持 `autoLockStartElev`（落笔瞬间自动锁定起笔海拔并向四周推平）及 `Alt + 点击` 吸管；
     - `terrace`：按 `terraceStepM` 将高程向最近阶地整数倍平滑收敛 `target = Math.round((current - baseElev) / step) * step + baseElev`；
     - `ramp`（斜坡拉道）：`pointerdown` 记录起点 `A` 与 `Z(A)`，拖拽过程只画预览斜坡带，`pointerup` 时调用 `applyRampStroke(field, A, B, Z(A), Z(B), radiusM, hardness)` 一次拉出均匀过渡斜坡！
     - `smooth`：窗口高斯-拉普拉斯平滑；
     - `erase`（微雕橡皮擦）：将 `field.sculptDelta[idx]` 按权重平滑衰减归零，同步更新 `field.elevation[idx]`，随时局部还原原始地形；
   - **`contour_drag` 解除硬编码**：使用 `state.brush.radiusM` 与 `state.brush.strength`，不再写死 `90 / 0.85`。
4. **PS 级画布笔刷快捷键**：
   - `[` / `]` 缩放半径（×0.85 / ×1.18）；`Shift + [` / `]` 调硬度（±0.1）；
   - `Shift + 滚轮` 原地缩放笔刷半径（不缩放画布）；
   - `tree_brush`：拖拽时按 `spacing = 0.75 * radiusM` 在笔刷圆内用确定性哈希撒点，过 `guardSafeTree` 写入 `project.paintedTrees`；按住 `Alt`（或选擦除模式）删除半径内所有 `paintedTrees`。

  - `dock`：`slipway` 绘制护岸石砌岸坪 + `slips` 道平行涂脂凹槽滑道（如北埠四道滑道）；`wooden_pier` 绘制岸坪 + 伸入水中的木栈桥与泊船细廓；支持放置/拖拽时**自动吸附最近河岸或湖岸并对齐外法向**；
  - `watermill`：吸附岸线，绘制石基工坊屋体 + 侧挂伸入水流的水轮齿圈；
  - **道路 × 明渠小桥**：`solveOrthogonalBridges` 除跨 `rivers` 外，对跨非 `qanat` 的 `canals`（`widthM >= 3.5`）同样自动生成石板小桥；
  - **桥梁覆写（`bridgeOverrides`）**：匹配 `35m` 内最近桥位，若为 `fortified_twin`，在桥头两端生成带角楼的方形石砌桥头堡（`fortSizeM × fortSizeM`，如帕隆停战桥）；若为 `ford` 则转为涉水踏步渡口；
  - **水渠 × 城墙水门（`wallBuilder.ts`）**：城墙额外与明渠求交，在交点生成拱形水门豁口（宽度 `canal.widthM + 2.5m`），避免水渠横切城墙。
- **核心建筑群构建（`customStructures.ts`）**：
  - 将 `project.structures` 精确转为真实建筑多边形：`rect`（矩形殿/仓）、`l_hall`（6 顶点曲尺 L 形厅）、`u_court`（8 顶点三合院/客舍大院）、`round_altar`（16 边圆坛 + 内环台基）；
  - 全部作为高优先级刚性障碍写入 `ObstacleGrid` 与 `spatialHash`，**先于普通民房生成**，确保周边民居与林木自动退让；
  - `hitTest.ts` 与 `paintHandles.ts` 支持点选、中心拖拽、旋转柄拖拽、长宽缩放柄拖拽与右侧精确输入（`selection.type` 扩展 `'weir' | 'dock' | 'watermill' | 'structure' | 'bridge'`，拾取顺序置于 `zone` 之前）。

### 3.3 山水地图学质感与双模出版导出（`src/core/terrain/terrainShading.ts` + `paintScene.ts`）
